瓜子影视 · TVBox 接口源

把瓜子影视的影视内容封装成 TVBox / 影视仓可直接加载的爬虫接口

type 3 · JAR 爬虫 csp_Gz360 支持搜索 / 筛选 无需账号

交付文件

文件用途
api.json 本地包版配置，jar 走相对路径 ./lib/tvkj.jar，自托管部署用
api-online.json 在线版配置，jar 走公网直链，可直接填进 TVBox 配置地址
lib/tvkj.jar 爬虫包，内含 com.github.catvod.spider.Gz360，2.0 MB

三种接入方式

1本地包（推荐）

整个文件夹丢进盒子存储，配置地址填 file:///sdcard/TVBox/…/api.json，不依赖任何第三方 CDN。

2在线订阅

把 api-online.json 托管到自己的服务器或仓库 raw 地址，填进 TVBox 的配置地址即可。

3并入已有接口

把那一个 site 对象追加进你现有配置的 sites 数组，全局 spider 不用动。

技术要点

项目说明
通信加密请求体 AES-128-CBC 加密 → 密钥经 RSA(PKCS#1 v1.5) 打包 → MD5 签名；响应反向解密
签名盐固定串 *&zvdvdvddbfikkkumtmdwqppp?|4Y!s!2br
设备认证自动走 /App/Authentication/Device/signUp 匿名注册并刷新 token
接口域名apinew.uozvr.com / api.w32z7vtd.com / api.6a7nnf7.com 等多域名轮询
内容分类电影 / 电视剧 / 动漫 / 综艺 / 短剧，支持地区 + 年份 + 排序三段筛选
jar MD5b9584d007155b163aa5cd92a4fd4ceda
为什么不能用 JS 规则源（drpy）？
瓜子是 AES + RSA 双层密钥交换再加 MD5 签名，且响应用私钥解密 —— JS 沙箱里既没有 RSA 原语也拿不到那一对密钥，只能走 JAR 爬虫。

排错提示

  • 放不出画面 — 先查 jar 是否下载完整。带 ;md5; 校验的地址，MD5 不匹配 TVBox 会直接拒绝加载。
  • 搜索有结果、点播报错 — 瓜子对请求头敏感且域名会轮换；原域名全挂时需要按新版客户端重新抓取域名列表并替换 jar。
  • 推荐在电视端用本地包 — 避免公网 CDN 抽风导致的加载失败。
